## Commits

- Follow [Conventional Commits](https://www.conventionalcommits.org/): `<type>(<optional scope>): <description>`, e.g. `feat(landing): add system scene`, `fix: keep URL hash in sync on scroll`. Common types: `feat`, `fix`, `refactor`, `style`, `docs`, `test`, `chore`, `perf`, `build`, `ci`.
- Keep commits atomic: one logical change per commit, and each commit should build and work on its own. Split unrelated changes (e.g. a refactor and a feature) into separate commits.

- Never add Claude (or any AI assistant) as a co-author. No `Co-Authored-By` trailers or "Generated with" attribution lines in commit messages or pull request descriptions.
